# Fantasy Football Assistant

A personal assistant for managing fantasy football teams across multiple leagues and platforms (e.g. ESPN, Sleeper, Yahoo, NFL.com). Built and documented in the open as part of an active job search portfolio.

## Purpose

- Centralize team management across leagues that otherwise live in separate, disconnected platform apps
- Support weekly decisions: lineups, waivers, trades, matchup prep
- Serve as a demonstrable, real-world project for job applications — showing product thinking, iterative build decisions, and applied use of AI tooling

## Status

Design phase complete for the initial scope — architecture, data model approach, and UI/UX for all five app sections (Draft, In-season, Exposure, League settings, W-L tracking) are defined. See [CLAUDE.md](./CLAUDE.md) for the current-state spec and [DECISIONS.md](./DECISIONS.md) for the full history of how it got there. Implementation is starting now, beginning with the data model and the draft tool.
